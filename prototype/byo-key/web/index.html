StoryTeller, bring your own key

Prototype (issue #13). Research and modelling run in this page using your Anthropic API key. Nothing is sent to us.

Your key stays in this tab's memory. It is sent only to api.anthropic.com. It is never stored, logged or put in a URL. Use a key with a spend limit. Running a story spends real money on that key: the cap below stops it, but search fees are not included in the counter.
